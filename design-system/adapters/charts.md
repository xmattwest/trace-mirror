# Charts and scientific figures

## Start with the estimand

State the quantity, unit, direction, denominator, sample, and uncertainty before selecting the chart. A plotted effect should not be confused with the raw outcome or with a different estimand. Use direct labels wherever practical.

Bars compare categories, lines show ordered/continuous change, scatter shows association, and interval plots show estimated effects with uncertainty. Preserve zero for magnitude-encoded bars unless an explicit alternative is warranted and disclosed. Use honest axis ranges and appropriate precision.

## Color and geometry

Blue Slate is the primary series. Sage is an optional secondary series, with Blue Slate essential outlines or a distinct dark line pattern on Ivory. Orange marks one selected item with dark essential supporting geometry. Do not force more series into five indistinguishable colors: use line patterns, symbols, small multiples, or a scoped accessible categorical extension.

Use 16 px labels and 14 px captions at final document/web size; use 32 px labels on the slide canvas. A wide chart scrolls locally on mobile when recomposition would lose meaning. The companion text or data table must remain available without operating the chart.

## Evidence conventions

Keep confidence levels explicit. If thick bars show 90% and thin bars 95%, name both. An equivalence band is a test margin, not a confidence interval. Do not infer equivalence from a non-significant test. Different models, sampling settings, or samples can limit comparisons even when displayed together.

When an estimand conditions on agreements, report disagreement/exclusion information alongside it. Preserve direction and counterexamples. Distinguish a registered result from an exploratory mechanism account.

## Review and export

Validate geometry against source values, not manually typed labels. Render titles, descriptions, labels, and intervals from the same evidence object. Check data bounds, precision, source receipts, readable fonts, grayscale interpretation, SVG viewBox clipping, and final-size export.

The calibration interval plot uses a common axis, a solid zero reference, dashed ±10 pp margins, dark interval lines, and redundant circle/square markers. It has no causal diagram: the primary analysis does not establish a mechanism.
