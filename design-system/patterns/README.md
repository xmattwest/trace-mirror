# Information patterns

Patterns describe information structure. The medium adapter decides their geometry.

| Pattern | When to use | Required content | Cross-medium expressions |
| --- | --- | --- | --- |
| Claim + evidence | One consequential statement | Claim, source, evidence status, relevant qualification | Memo lead; slide assertion; result block |
| Mechanism | A known process or hypothesised account | Steps/relations, what is observed versus inferred | Process figure; explanation section; workflow UI |
| Comparison | Evaluate options or conditions | Shared dimensions, units, explicit differences | Table; aligned panels; decision screen |
| Overview + detail | Necessary complexity exceeds one frame | Stable overview, navigable details, omissions ledger | Summary plus appendix; drill-down; linked figures |
| Artifact + inspection | The work itself is the reader's reason to visit | Artifact, concise orientation, useful controls or annotations, inspectable source | Interactive explorer; visual specimen; tool with a working launch command |
| Annotated result | An empirical quantity needs interpretation | Estimand, labels, uncertainty, sample, takeaway | Chart; scientific figure; slide evidence |
| Decision + next step | A reader must act or decide what to study next | Implication, scope, one clear action/question | Recommendation memo; CTA; recovery state |

## Example: one claim, four expressions

The Study 2 calibration says seller-share response is model-dependent in this setup. Its memo carries an evidence table and caveat. The slides separate design, result, and qualification. The web section offers progressive depth through an evidence disclosure. The figure preserves both uncertainty levels and the registered margin.

The templates never replace unknown mechanisms with causal arrows. They do not repeat a decorative three-card grid across every medium.

An overview is an information structure, not a mandatory hero section. Select an opening that gives the reader something specific to understand or use. Descriptive titles, artifact-first views, and evidence-led questions are all valid starting points.
