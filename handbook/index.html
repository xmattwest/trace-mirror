A persona and language signals, with scoring rules and message counts you can inspect.

Daily rhythm

A snapshot to keep

Save a PNG share card or an offline HTML report, without prompts or source paths.

Run locally

python3 mirror.py

Unzip the download and run the command from that folder. Mirror opens http://127.0.0.1:8787/. Without --db, it tries OpenCode’s usual data directory or lets you enter a path.

Set up with an agent

Give your agent agent-setup.md, or send this:

Set up OpenCode Mirror on my computer using
https://xmattwest.github.io/trace-mirror/agent-setup.md
Archive path, timezone and export
python3 mirror.py --db "/path/to/opencode.db"
python3 mirror.py --db "/path/to/opencode.db" --timezone America/Denver
python3 mirror.py --db "/path/to/opencode.db" --export mirror.html

The app uses your browser’s timezone; headless exports use the computer’s zone, with UTC as a fallback. An explicit override takes precedence. Daylight saving follows each message’s date, and snapshots retain their original zone.

Other options: --port 8788, --no-open, --version.

Method and privacy

The persona is a transparent heuristic, not a validated personality test. Fewer than 20 filtered messages produces an early sketch. Root user text excludes synthetic/ignored parts, reminders and identifiable history copies. Pasted material can still influence the result. Activity measures interaction, not hours worked.

The database stays read-only. Nothing is uploaded. Exports exclude prompts, tool inputs and outputs, full paths, session IDs and credentials. Shared HTML aliases project names; dates, aggregate counts and model/tool names remain.
